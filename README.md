# 🏛 ArchiveBot 🏛
***ArchiveBot*** is a multi-server discord bot that's meant to connect the "CivBound" community, link by link. This is a public repository for those who are interested, and to ensure it's safety for users.

# 📋 Features
- ⚖️ `/Help` - *Sends the* ***ArchiveBot*** *Help Menu*
- 📌 `/Info` - *Sends information about* ***ArchiveBot***
- 🔍 `/Search` - *Search for a specific server*
- 🎲 `/Random` - *Sends a random server*
> **Command List:** [Here](https://github.com/GamingDerp/CBArchiveBot/blob/main/COMMANDS.md)
